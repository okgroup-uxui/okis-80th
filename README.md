## 스크롤 스냅 동작 — 페이지 단위 정지

`html.snap-pages { scroll-snap-type: y mandatory }` + 정지점마다 `scroll-snap-stop: always`.

섹션 높이가 714~1600px로 화면보다 크기 때문에, 섹션에 바로 `mandatory`를 걸면
스냅 영역이 화면보다 커져 mandatory가 무력화되거나 섹션 하단이 스냅에 가려집니다.
그래서 `main.js`가 **섹션을 화면 높이에 맞춰 페이지로 쪼갠 뒤 각 페이지 시작점에
1px 정지점(`.snap-mark`)을 심는** 방식으로 처리합니다.

- 섹션 높이 ≤ 화면 → 정지점 1개 (섹션 머리)
- 섹션 높이 > 화면 → `ceil(높이 / 화면)`개, 마지막 정지점은 섹션 끝에 정확히 맞춤

마지막 정지점을 섹션 끝에 맞추기 때문에 **스냅 때문에 못 보는 내용이 생기지 않습니다.**
390×844 기준으로 정지점은 11개가 잡힙니다.

정지점은 화면 크기가 바뀔 때(회전, 창 크기 조절, 웹폰트 로드 완료) 다시 계산됩니다.
모바일 주소창이 접히며 생기는 높이 변화(120px 미만)로는 재계산하지 않습니다.

**입력 방식별 동작**

| 입력 | 동작 |
|---|---|
| 모바일 터치 스와이프 | 한 번에 한 페이지씩 정지 |
| 트랙패드 | 한 번에 한 페이지씩 정지, 짧게 밀면 제자리로 되돌아옴 |
| 키보드 PageUp/PageDown | 한 페이지씩 정지 |
| 마우스 휠(큰 노치) | 한 번에 두 페이지를 넘어갈 수 있음 |

마지막 항목은 Chrome이 큰 휠 델타를 하나의 스크롤 연산으로 처리해
`scroll-snap-stop`을 건너뛰는 경우입니다. 스크롤을 되돌리면 정상적으로 잡히고,
주 타깃인 모바일 터치에서는 발생하지 않습니다.

**되돌리려면**: `main.js`의 `buildStops()` 호출부를 지우면 CSS 폴백인
`scroll-snap-type: y proximity`(섹션 경계 근처에서만 붙고 섹션 내부는 자유 스크롤)로 동작합니다.

우측 인디케이터(6개 점)로 섹션 간 즉시 이동이 되고, 어두운 배경 섹션에서는 자동으로 밝은 색으로 바뀝니다.
